# Сервер программы лояльности

Регистрация и аутентификация пользователей, ведение бонусного счёта, списка заказов, истории списаний.
Общение с системой расчёта бонусов.

## Запуск

Скомпилированный бинарный файл принимает следующие флаги и переменные окружения(флаги имеют больший приоритет над переменными окружения):

 - Адрес системы программы лояльности (по умолчанию localhost:8080)
> Флаг "-a" или переменная окружения "RUN_ADDRESS"

- Адрес системы расчёта начислений (по умолчанию localhost:8081)
> Флаг "-r" или переменная окружения "ACCRUAL_SYSTEM_ADDRESS"

- Адрес подключения к базе данных
> Флаг "-d" или переменная окружения "DATABASE_URI"

- Токен проверки аутентификации
> Флаг "-j" или переменная окружения "JWT_TOKEN"

## Тестирование

Для удобства тестирования в репозитории расположен Makefile с сокращёнными командами

 - `make tests` - Проведение тестов
 - `make test-cover` - Подсчёт покрытия тестами
 - `make test-cover-view` - Подсчёт покрытия тестами c детализацией в браузере
 - `make test-cover-total` - Общая цифра покрытия кода тестами
